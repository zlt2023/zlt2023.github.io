3. 配置 Git

二、创建 GitHub 仓库

1. 创建仓库

  1. 登录 GitHub，点击右上角 + → New repository
  2. 仓库名称填写：你的用户名.github.io（例如：zhangsan.github.io）
  3. 选择 Public（公开）
  4. 勾选 Add a README file
  5. 点击 Create repository

⚠️ 注意：仓库名必须是 用户名.github.io 才能作为 GitHub Pages 的域名。

2. 配置 GitHub Pages

  1. 进入仓库的 Settings 页面
  2. 左侧菜单选择 Pages
  3. Branch 选择 main，文件夹选择 /(root)
  4. 点击 Save

稍等几分钟，访问 https://你的用户名.github.io 就能看到默认页面了。

八、部署到 GitHub

1. 执行部署

2. 首次部署需要认证

如果是第一次使用，会提示输入 GitHub 用户名和密码：

  • 用户名：你的 GitHub 用户名
  • 密码：不是登录密码，而是 Personal Access Token

创建 Personal Access Token：

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. 点击 Generate new token
  3. 勾选 repo 权限
  4. 生成后复制 token 作为密码输入

3. 访问博客

等待约 1-2 分钟后，访问 https://你的用户名.github.io 即可看到你的博客！

十、常见问题

Q1: 部署后页面空白或样式丢失？

检查 _config.yml 中的 url 配置是否正确，确保与你访问的地址一致。

Q2: 如何绑定自定义域名？

  1. 在 source 目录下创建 CNAME 文件，内容为你的域名（如 www.example.com）
  2. 在域名服务商处添加 CNAME 记录指向 你的用户名.github.io
  3. 在 GitHub Pages 设置中配置自定义域名
